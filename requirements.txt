#
# Runtime Requirement:
#   Python >= 3.11 (uses standard library: http.server, pathlib, html, json, math, re)
#
# Visual Studio / VS Code Setup Steps:
#   1. Open this project folder in Visual Studio or VS Code
#   2. Select a Python 3.11+ interpreter (or create a virtual environment):
#        python -m venv .venv
#   3. Activate the environment and install requirements:
#        Windows (PowerShell): .\.venv\Scripts\Activate.ps1
#        macOS / Linux:        source .venv/bin/activate
#        pip install -r requirements.txt
#   4. Set startup file to: server.py
#   5. Run the app:
#        python server.py
#   6. Open in browser:
#        http://localhost:3000
#
# Note: All core review and lexical analysis modules (server.py, app.py,
# lexical_analyzer.py) use the Python standard library with built-in fallback,
# and no external API keys are required.
